THE SHORT VERSION

Hi, I'm Drag00nKnight999.

I'm a programmer and creator interested in building web experiences, gaming platforms, and custom game systems. I like taking an idea, testing it, and improving it until it works better.

My projects span static websites, account-based web apps, community concepts, and Bloxd.io world-code experiments.

What I enjoy building

  • Websites that are clear, responsive, and easy to navigate
  • Game features, custom mechanics, and API experiments
  • Useful admin tools, project status pages, and documentation
  • Small prototypes that can grow into larger projects

How I approach projects

I prefer shipping in small steps: make a working version, test it, document known limitations, and iterate. Not every experiment becomes a finished product, and that's part of learning.
